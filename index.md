# Care Reminders test privacy notice

Care Reminders is operated by Eric Logothetis in the UK. For privacy questions or requests, email Care.Reminders@gmail.com.

## What this test uses

Care Reminders is being developed and tested with fictional appointment records stored in the local browser. Please do not enter real patient information. Live patient messaging is disabled.

Eric Logothetis’s personal phone is the only WhatsApp test recipient. The phone number is used with his agreement to send an approved, generic Hello World message and check whether it arrives. Test messages contain no appointment or patient information. Eric can stop testing and withdraw his agreement at any time.

## Services used during testing

Meta’s WhatsApp Cloud API processes the test phone number and message to deliver the test. Meta sends delivery updates, which can include the recipient’s number, a message identifier, status and timestamp. These updates pass through a temporary Cloudflare connection to the local Care Reminders server. Meta and Cloudflare may process information outside the UK. Their privacy information is available at [WhatsApp Legal](https://www.whatsapp.com/legal/) and [Cloudflare’s privacy policy](https://www.cloudflare.com/privacypolicy/).

GitHub Pages hosts this notice. GitHub says it logs visitors’ IP addresses for security purposes. See [GitHub’s privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## How long test information is kept

Care Reminders keeps the current test’s delivery status in memory until the local server restarts. When testing ends, Eric will remove his phone number from the local Care Reminders settings and Meta’s test recipient list.

## Privacy requests and complaints

To ask about test information or request access, correction or deletion, email Care.Reminders@gmail.com. You can also raise a data protection concern with the [UK Information Commissioner’s Office](https://ico.org.uk/for-the-public/how-to-make-a-data-protection-complaint/).
